# ❤️ Heart Disease Prediction System

An end-to-end Machine Learning web application that predicts the likelihood of heart disease using patient health information. The application is built with **Python**, **Scikit-learn**, and **Streamlit**, and is deployed on **Streamlit Community Cloud**.

## 🌐 Live Demo

**Live Application:** https://heart-disease-predition-njacq3gymw2v3j6iap8qzw.streamlit.app

## 📂 GitHub Repository

**Repository:** https://github.com/ashik230509/Heart-Disease-Prediction

---

## 📌 Features

- Predicts whether a patient has heart disease.
- Interactive and user-friendly Streamlit web interface.
- Displays prediction confidence.
- Uses a trained Logistic Regression model.
- Fast real-time predictions.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/ashik230509/Heart-Disease-Prediction.git
```

Move into the project folder:

```bash
cd Heart-Disease-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
